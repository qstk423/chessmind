# 指导与评价演示素材

这两个文件均用于国际象棋。PGN 记录连续走法，FEN 记录 PGN 最后一手后的局面。

## PGN 分析

1. 切换到国际象棋，进入「工具 → PGN 导入」。
2. 将 council-demo.pgn 的全部内容粘贴到输入框，点击「分析 PGN」。
3. 等待逐步分析结束，页面应显示共分析 5 步（5 个半回合）。
4. 可围绕黑方 2…f6 与白方 3.Nxe5 展示逐步评价。模型分析耗时受网络影响。

PGN 分析会展示着法评价，不会自动覆盖当前对局棋盘。

## FEN 加载

1. 进入「工具 → FEN 导入」。
2. 将 council-demo.fen 的一整行内容粘贴进去，点击「加载局面」。
3. 软件自动进入双方可操作的自由推演模式；白马在 e5，白兵在 e4，黑兵在 f6，轮到黑方。
4. 如需讲解该局面，进入工具点击「分析当前局面」。

文件使用的是国际象棋格式，请勿粘贴到中国象棋的 FEN 工具中。
