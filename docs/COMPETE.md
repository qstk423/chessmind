# ChessCouncil · 天津移动 Token 算力大赛冲奖手册

## 一句话定位

**ChessCouncil**：多模态棋局感知 + 异质多智能体分析与动态辩论 + Stockfish 引擎仲裁的实时国际象棋系统（赛道二 · AI 游戏 / 算法对抗）。

## 路演 5 分钟结构（决赛）

| 时间 | 内容 |
|---|---|
| 0:00–0:30 | 痛点：纯引擎不会讲；纯 LLM 会幻觉；多 AI 各说各话无仲裁 |
| 0:30–2:00 | **顶部「路演 Demo」**：希腊赠礼 → 争议度飙升 → 自动辩论 → 引擎仲裁 |
| 2:00–3:00 | 「对弈设置 → 高级选项 → 快速 AI 对战」：算法对抗（关 Council 提速） |
| 3:00–3:40 | （可选）「更多工具 → 拍照识谱」；失败则跳过，强调 FEN 纠错 |
| 3:40–4:20 | 棋盘旁点 **复盘**，或 Demo 结束后自动打开的赛后复盘 |
| 4:20–5:00 | 「更多工具 → 调用证明」展示 `llm_calls` + 收束三句创新点 |

## 创新点（评委三句）

1. **异质 Agent**：战术 / 战略 / 风险职责互斥，不是同一 prompt 复制粘贴。  
2. **分歧驱动辩论**：可解释加权争议度，高争议才辩论，省 Token 也更像「理事会」。  
3. **引擎接地 + 仲裁**：事实来自 python-chess / Stockfish，LLM 不能瞎编局面。

## 现场操作顺序（与当前 UI 一致）

1. `python -m src.main`（或 `docker compose up`）→ 打开 http://127.0.0.1:8000  
2. 顶栏确认模型 pill 为已启用 → 点 **「路演 Demo」**  
3. 等顶部进度结束 → 侧栏自动切到 **辩论** Tab；下方提示条引导复盘  
4. Demo 成功后会自动打开 **更多工具 → 赛后复盘**；也可点棋盘下 **复盘**  
5. 切到 **对弈设置 → 高级选项 → 快速 AI 对战**（关 Council，快进算法对抗）  
6. 切到 **更多工具 → 调用证明 → 刷新日志**（或 `tail -f logs/llm_calls.jsonl`）

### 一键导出证据包（录屏前后都可跑）

```bash
source .venv/bin/activate
python scripts/export_pitch_evidence.py
```

产出目录：`docs/pitch/evidence/`（复盘 JSON、日志摘录、分镜说明）。

## 录屏（提交用，3–5 分钟）

### 工具

macOS：**QuickTime Player → 文件 → 新建屏幕录制**（选浏览器窗口，系统音频按需）。

### 分镜口播稿

| 镜号 | 画面 | 口播要点 | 操作 |
|---|---|---|---|
| 1 | 首页品牌 + 模型 pill | 痛点三句：引擎不会讲 / LLM 会幻觉 / 多 AI 无仲裁 | 停留 5–8s |
| 2 | 点「路演 Demo」→ 进度条 | 异质 Agent 并行；高争议才辩论 | 等 Council 结束 |
| 3 | 侧栏「辩论」+ 争议度条 | 展示质询 / 答辩 / 仲裁结论 | 滚动辩论内容 |
| 4 | 赛后复盘 | 争议步、辩论次数、PGN | Demo 后自动打开或点复盘 |
| 5 | 快速 AI 对战走几步 | 算法对抗：LLM vs Stockfish，非法着回退引擎 | 高级选项 → 快速 AI 对战 → 走 4–8 步后暂停 |
| 6 | 调用证明 | 证明真实调用（模型名 / latency / tokens） | 更多工具 → 调用证明 → 刷新 |
| 7 | （可选）识谱 | 多模态入口；失败可跳过 | 更多工具 → 拍照识谱 |

### 录制勾选

- [ ] 镜 1–3 辩论完整出现（勿从空棋盘硬讲辩论）  
- [ ] 镜 4 复盘有数据  
- [ ] 镜 5 至少 4 步自动走子  
- [ ] 镜 6 日志里能看到本次 Demo 的 agent 行  
- [ ] 导出 `logs/llm_calls.jsonl` 与视频一并提交  

## Token 切换（大赛发下来后）

编辑 `.env`（不要提交真实 Key）：

```ini
LLM_API_KEY=<天津移动>
LLM_BASE_URL=<天津移动兼容 OpenAI 的地址>
LLM_MODEL=glm-5.1
VISION_MODEL=<官方视觉模型；暂无则继续用 qwen-vl-plus 仅开发演示>
```

重启服务后顶栏 pill 应显示 `glm-5.1`。开发期可用千问（`qwen-plus`），**提交 / 决赛现场以 glm-5.1 为准**。

## 风险预案

| 风险 | 预案 |
|---|---|
| API 超时 | 取消勾选 Council，纯引擎对战仍可演示；播预录视频兜底 |
| 开局无辩论 | 必须用 **路演 Demo**，不要从初始局面硬讲辩论 |
| 识谱失败 | 跳过 multimodal，强调 FEN 纠错 + Demo |
| 超时 | 缩短 Agent max_tokens；Demo 只跑一局；快速 AI 关掉 Council |
| 旧页面缓存 | 硬刷新；确认顶栏是「路演 Demo」而非旧路演条 |
